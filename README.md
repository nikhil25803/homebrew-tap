# Nikhil's Homebrew Tap

Homebrew tap for command-line tools and utilities by [@nikhil25803](https://github.com/nikhil25803).

## Installation

Add the tap:

```bash
brew tap nikhil25803/tap
```

Then install the tools you need.

## Available Formulae

### purrpeek

**Your system information, from a cat's perspective. Purr approved.**

```bash
brew install nikhil25803/tap/purrpeek
```

Repository: https://github.com/nikhil25803/purrpeek

## Updating

Update the tap and upgrade installed formulae:

```bash
brew update
brew upgrade
```

To upgrade only `purrpeek`:

```bash
brew upgrade purrpeek
```

## Uninstalling

To uninstall a formula:

```bash
brew uninstall purrpeek
```
